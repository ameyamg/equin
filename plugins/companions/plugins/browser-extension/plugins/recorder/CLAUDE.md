# companions/browser-extension/recorder

The browser extension's tab recorder, equin's half. The session itself runs
in the extension's shell (`../../browser-extension/background.ts`,
`offscreen.ts`, `content.ts`; see `../../CLAUDE.md` § The tab recorder). Plan:
`research/2026-11-15-companions-chrome-window-recorder-v2.md`; UI: the popover
prototype `proto-1794537939-tuvpg1` ("Record").

- **`web/`** — the Record section (`BrowserExtension.Section` "record"): the
  row (size dropdown — each entry named by the page size it lays the tab out
  at, its common name and this display's video size beneath; one the tab
  cannot record now (`presetFit` over the tab measured by the shell) stays
  choosable with a Too big / Zoomed badge —, Apply beside it (the
  worker's `recorder.apply-size`: sizes the window to the preset's page now,
  no recording, nothing restored), the four toggles, the
  round Record button), the recording card, the saved row (Show in Files opens
  the explorer's own route on the file; Delete is the explorer's
  `computerFileTrash`). The section's geometry is `web/internal/record.css`,
  the prototype's numbers on theme tokens. And the **relay page**
  (`recorderRelayApp`, `/home/browser-extension-recorder`): framed by the
  offscreen document, it posts each chunk to the endpoints below, same-origin.
- **`core/`** — the Recordings folder setting (`recorderConfig`, default
  `~/Movies/equin`; the recorder's other options are the extension's own, in
  Chrome's storage, so ⌥⇧R needs no equin read), the endpoints, the file name
  (`<YYYY-MM-DD HH.MM> <title>.mp4`).
- **`machine/`** — the endpoints. A recording is a hidden
  `.<id>.partial.mp4` appended chunk by chunk (strictly in order:
  `chunkDecision`), then fsynced, remuxed by ffmpeg (`-c copy -movflags
  +faststart`, the `media/ffmpeg` dep, requested on first use) and linked to
  its final name (never overwriting: ` (2)`…). Uploads in flight are held in
  memory: a backend restart mid-recording makes it fail loudly, the partial
  file kept in the folder. No DB table, no live collection: listing the folder
  is the file explorer's (and a future editor's) job.
