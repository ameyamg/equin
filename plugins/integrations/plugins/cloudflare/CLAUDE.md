# cloudflare

A stateless client for Cloudflare's v4 API, in the style of `integrations/resend`:
the token is a parameter, and the plugin knows nothing about who calls or why.
`server` only (a raw `fetch` is no browser's business); the deploy CLI calls it.

- `listZones(token)` — every zone the token can read (`Zone · Zone · Read`);
  50 or more is refused (a deploy token is scoped to the zones it deploys).
- `zoneOfHostname(zones, hostname)` — the zone whose name is the hostname or
  its longest parent domain, or null.
- `purgeCacheTags(token, zone, tags)` — drop every object the edge cached
  under these `Cache-Tag`s (`Zone · Cache Purge · Purge`). A tag no object
  carries is a successful no-op, which is how a deploy probes the token's
  permission before it touches a host.
- Every answer's `{ success, errors, result }` envelope is zod-parsed; a
  refusal throws `CloudflareApiError` with Cloudflare's own reasons, no answer
  throws naming the step. No retry.

The token itself is the `cloudflare` account in Settings → Accounts
(`auth/cloudflare`). First consumer: `framework/cli/deploy` (a `cloudflare`
edge's HTML cache, purged on every ship).
