# render-loop/activity

Page activity the render-loop detector's idle gate counts besides this tab's
own input (pointer, keys, scroll, resize). A leaf library with no imports, so
the code that knows about the activity — a player, the web-storage store —
marks it without depending on the detector.

- `holdPlayback()` / `playbackHeld()` — a playback timeline is running (see
  the parent's *Playback*).
- `markRemoteInput()` / `lastRemoteInputAt()` — another tab's write was just
  handed to a reader in this page (see the parent's *Remote input*).

Mark only real activity: each mark silences the detector for IDLE_MS.
