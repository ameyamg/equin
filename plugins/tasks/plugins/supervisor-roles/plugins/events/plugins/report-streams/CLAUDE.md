# report-streams

The report event streams, one per report category (`reports/core`'s
`REPORT_CATEGORIES`), each fed every recorded report of its category by a
`ReportRecorded` listener:

- **Error reports**, **Slow-op reports** — one event per
  occurrence, keyed by the report, gathered into the routed role's next
  message.
- **Broken tests** (category `test`: `test-failing`) — announces the same
  way. The role it is routed to (Supervisors pane) is told about each broken
  test file's report and decides what to do; nothing files a task for it
  (a task per broken test was tried and removed on user feedback, 11-23).
