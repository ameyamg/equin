# report-streams

The report event streams, one per report category (`reports/core`'s
`REPORT_CATEGORIES`), each fed every recorded report of its category by a
`ReportRecorded` listener:

- **Error reports**, **Slow-op reports** — ANNOUNCE: one event per
  occurrence, keyed by the report, gathered into the routed role's next
  message.
- **Broken tests** (category `test`) — OWNS its reports: a broken test is one
  unit of work, fixed by one change and closed by the fix ledger, so each open
  report gets exactly one investigation task (`investigateReport` with a
  system requester): in the backlog of the role the stream is routed to
  (unless the route's kinds leave the kind out), else a plain Reports task.
  The route is the one "who owns broken tests" setting. On its occurrence
  (the listener fires for a report no task is linked to, and again when a
  regression unlinks it) and at main's boot for every open report with no
  task, or a dropped one (`supervisor-events.own-open-reports`). Only the
  host's own backend files: a worktree's roles and reports are a fork of
  main's.
