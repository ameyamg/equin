# cloudflare

The Cloudflare API token, as an `apikey` account in Settings → Accounts. A
deployment whose `edge` is `cloudflare` needs it: converge and ship refuse
without it, and every ship purges the site's cached HTML with it
(`framework/cli/deploy`).

- `core` — `CLOUDFLARE_PROVIDER_ID`, where tokens are made, and the two
  permissions the token needs (`Zone · Zone · Read`, `Zone · Cache Purge ·
  Purge`) — nothing that edits the zone.
- `central` — the descriptor. `verify` accepts a token only once Cloudflare
  says it is active (`/user/tokens/verify`). What it may do on which zone is
  checked where it is used: a deploy reads each hostname's zone and probes a
  purge there before touching the host (`framework/cli/deploy`).
- `web` — the Accounts row and its steps (make the token, paste it).

The API calls are `integrations/cloudflare`'s; this plugin only holds the
credential.
