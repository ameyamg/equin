# history

The sleeps this process has seen, for any code that judges an age on awake
time — on every host, from any folder.

**Why a leaf of its own.** Reading the OS sleep clock needs `bun:ffi`
(`packages/sleep-clock`'s `readSleepClock`), so code every host runs —
server-core's `core/`, the portable change feed — could not import it, and
the history built on it lived in `infra/host/machine-sleep/server`, which
`core/` cannot import and the change feed could not without a cycle. Every
such site fell back to the wall clock with a `debt` exemption. The history
itself is pure arithmetic over readings, so it lives here and imports nothing
that needs the computer; the one native part — the reader — is **installed**
by the host:

- `installSleepClock(readSleepClock)` — the desktop's host probes
  (`server-core/bin/host-probes.ts`, both boot modes, before the graph loads)
  and `infra/host/machine-sleep`'s server half at module eval (so a CLI or any
  process importing it judges on the real sleeps too). Idempotent for the same
  reader; a second, different reader throws.
- A host that installs none (a page's worker, the demo) has no sleep clock:
  `sleptDuring` answers `null`, `awakeMsSince` the wall span — never shorter
  than the truth.

API (one process-wide history): `sleptDuring(start, end)`, `awakeMsSince(wallMs)`
(the awake age of a past wall instant nothing could stamp, e.g. a change's
`changedAt`), `stampOfWallInstant`, `awakeSpanStart`, `wakeBefore`, and the
set-if-changed reading `publishSleepReading` / `currentSleepReading` /
`onSleepReadingChanged` that machine-sleep serves as `machine.sleep`.
`readInstalledSleepClock()` reads the installed clock raw (server-core's
`_debug.linger`). `SleepClockReading` — the reading's shape — is declared here
and used by `packages/sleep-clock`.

Which tool for an age (a stamp, an awake timer, this history):
`packages/sleep-clock/CLAUDE.md` § Judging an age.

## Plugin reference

- Description: This process's sleep history, on every host: the sleeps it saw (plus the one before its first reading), fed by the sleep clock its host installs (installSleepClock — the desktop's host probes and machine-sleep install packages/sleep-clock's bun:ffi reader; a page's worker installs none and every answer is 'cannot tell'). sleptDuring(start, end), awakeMsSince(wallMs) — the awake age of a past wall instant nothing stamped (a Postgres commit's changedAt), the wall span where the sleep cannot be told — stampOfWallInstant, awakeSpanStart, wakeBefore, and the set-if-changed reading machine-sleep publishes. Portable and import-free of the computer, so core/ code and the portable change feed judge ages on awake time without a plugin cycle.
