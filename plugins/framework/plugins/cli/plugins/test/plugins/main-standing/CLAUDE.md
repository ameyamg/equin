# main-standing

Where a failing test file stands on main — the ONE notion of "already
failing on main", shared by `./equin test` (printed under a failing run) and
the push test gate (`push/plugins/test-gate`, which blocks only failures that
are not). Design: `research/2026-11-23-global-broken-test-ownership.md`.

- `core`: `judgeFailure` over a `VerdictIndex` of every harvested run on the
  host — the file's verdicts at the merge base's digest (any checkout, by
  majority, `not-loaded` ignored), else main's own newest — plus
  `describeJudgement` and `isProvingPass` (a pass that ran ≥ 1 case).
- `cli`: `readTestRunRecords` (the host-global `test-runs` dir),
  `mergeBaseDigests` (git objects, never the working tree), and
  `standingOnMain` / `standingLines`: each failing file's judgement with main's
  `test-failing` report and owner task (`debug/tests/failing-report`'s
  `readKnownTestReports`). Main's reports unreadable is said beside the
  judgements, never fatal.

The lines end with the rule agents follow: a failure already failing on main
is never filed again as a task — each has (or gets) one report and one owner
task, and the run is already recorded as evidence.
