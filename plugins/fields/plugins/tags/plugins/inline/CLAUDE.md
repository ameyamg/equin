# tags / inline

The **tags** (multi-value) type's `data-view.cell-editor` capability.

Contributes `DataViewSlots.CellEditor({ match: "tags", ... })` — a compact
`TagsEditor`: an open-by-default `InlinePopover` holding the shared tag picker
(`tag-tree/picker`'s `TagPickerPanel`, read-only — no writes) over
`field.options`, through `tagRowsOfOptions`: a forest when the options carry
`parent` (a tag tree's `tagFieldOptions`, a mail account's labels), roots
otherwise. Search finds a tag by its path, a click toggles it; an option marked
`fixed` (`FieldOption.fixed` — set by other means, a mail role) is neither
offered nor removed; a value the row holds that no option names (a tag
deleted since) is listed as a root of its raw value, so it can be removed.
The accumulated `string[]` commits on dismiss via
`onCommitValues` (the multi-value commit channel), or cancels if unchanged or on
Esc. It adds no tag the options do not hold: making a tag is the tag source's
own picker (`TagPickerPopover` with its writes).
