# media / config

The **media** type's config capability: `Fields.Renderer(MediaRenderer)` and
`Fields.Sample(mediaSample)`.

The renderer is a `block` shape whose control is one component
(`MediaEditor`, since it keeps per-mount state): the field's refs as
`MediaThumb`s in a wrapping `SortableList` (drag to reorder, × to remove),
then the shared `UploadDropzone` while there is room — `accept` and
`maxBytes` from the field, `maxFiles` the room `max` leaves (more files are
refused before any upload). The dropzone owns its focus (`focus={{ owner:
"self" }}`): Tab or a click focuses it, Enter / Space open the picker and
Cmd+V while it is focused uploads the clipboard's files — focus says which
dropzone a paste is for.

- **Uploads in turn.** The dropzone hands each file over from one async loop,
  so every commit builds on the latest committed value (`useLatestRef`), not
  on the render that started the loop.
- **Hold until linked.** Each upload joins this mount's hold
  (`holdAttachments`, holder `fields.media:<uuid>`, TTL 24 h; the whole set is
  sent, since a hold replaces the holder's previous one). The owner's save
  links the files (`mediaAttachmentIds`); nothing relies on the hold past it.
  A failed hold is shown under the dropzone.
- **Metadata.** A ref missing `width` / `height` / `durationMs` gets what its
  thumbnail's load read (image natural size, video metadata), once.

The sample is an empty field (a ref would name an attachment no other machine
has), so its gallery row shows the dropzone.
