# prompts

Agent prompts as config. Every instruction an agent reads from equin — a
system-prompt section, a `## Mandate` line, an automation's push policy — is a
prompt field the user sees and edits in Settings → Config, its default the
wording the code ships.

```ts
export const sourcePagePromptsConfig = defineConfig({
  name: "agent-instructions",
  fields: {
    sourcePage: promptField({
      label: "Source page",
      description: "Told to a task's agents when …",
      default: "The user filed this task while on {{url}} — …",
      variables: [{ name: "url", description: "the page's URL" }],
    }),
  },
});

renderConfigPrompt(sourcePagePromptsConfig, "sourcePage", { url }); // server
fillPrompt(descriptor, values, key, vars); // pure: tests (descriptor.defaults), web (useConfig)
```

- **`promptField`** is a multiline-text field (drawn as one) whose schema
  refuses a `{{name}}` it does not declare. `setConfig` parses the field
  schema, so the save is refused wherever it comes from; a hand-edited
  override naming one resolves to the origin as an invalid document. Its
  description lists the variables. A pane editing one checks
  `unknownTemplateVariables(value, field.variables)` before saving to say why.
- **`PromptText`** is what `fillPrompt` / `renderConfigPrompt` return, and the
  only thing a `SystemPrompt.Section` `render` and a `Mandate.Capability`
  `describe` may return: there is no `string → PromptText` door, so prose
  written in code does not type-check. `joinPrompts` (blank line or line
  break) and `promptList` (`- ` bullets) combine them; the separators are
  structure, never words.
- **Variables are data** — ids, titles, URLs, generated listings, or another
  prompt's rendered text. A sentence is never a variable's value written in
  code: it is a prompt of its own.
- **Name** it `agent-instructions` (its file name; one per plugin), unless the plugin's config already holds its prompts.
- **Register** the descriptor in the owner's server (`ConfigV2.Register`) and
  web (`ConfigV2.WebRegister`) barrels, so it shows in Settings → Config.
