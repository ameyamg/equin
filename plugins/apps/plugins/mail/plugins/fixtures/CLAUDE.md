# fixtures

Mail fixtures: a mailbox in Mail's own terms (`core`'s `MailFixture` — the
account, labels at `/` paths, threads of messages, every id the caller's,
times relative to now) and its writer (`server`'s `writeMailFixture`), which
writes one into the local mail provider (`apps/mail/providers/local`)
through its real write paths: the account, the labels through the
provider's own mailbox writes, each message through `localMail.deliver` (mail
arriving — no user endpoint makes received mail). It never goes through the
Mail cache, so a seeded host's cache is empty and fills on the first open,
against the (time-shifted) provider rows.

- A message's `mailboxes` are role names (`inbox`, `sent`, …) or label paths;
  absent is `["inbox"]` (`["drafts"]` for a draft), `[]` is archived.
- A label's `color` is a background of the provider's palette
  (`LOCAL_MAILBOX_COLORS`, Gmail's); anything else is refused.
- An attachment is inline bytes or a `dataPath` the caller's `readData`
  reads (the demo's `data/` folder).
