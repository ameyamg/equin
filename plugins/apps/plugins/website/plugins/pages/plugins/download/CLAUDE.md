# download

The download page at `/about/download` — how to run equin on your own Mac.

One install, offered two ways behind a tab: **For you**, the repository's
`install.sh` as one `curl … | bash` command (with what it does folded under
it), and **For your agent**, the same install as a prompt, copyable or opened
straight into Claude Code / the Claude app through their deep links (the prompt
is typed in; nothing runs until the reader presses Enter). Then the caveats as bullets —
the first install builds every app (~15 minutes), and the apps were tuned
for one person — and "Once it is running": open it, press Wish (no guide step
while the guide page is a placeholder). Last, two slim closing cards of one
shape (`DownloadCard`: a tile in the card's light, a title, a line, one pill):
**Learn the tricks** (the tips page, wearing the tips' bulb and warm light —
a guide link can join it once the guide is written) and **Try it in your
browser first** (the demo page, `/about/demo`, at its own start — this page
names no place inside it — saying its agents only run on the reader's
machine).

The command, the source link and the local app's address come from the shell's
`core/site.ts`, never spelled here, so the page cannot offer one repository's
installer beside another's source. The installer's steps are written out in
`download-install.tsx`; keep them in step with `install.sh`.
