# plots

Isle's stored placement: `isle_plots`, one row per plot of a world (`world` = `<seed>/<LAYOUT_GENERATION>`),
keyed `(world, plotId)`, its geometry one jsonb value and its `group` / `region` (the category the plot
was made for: leaf tag id and root tag id, `_` for none) columns. `placementOfRows` / `placementWrites`
map rows ↔ world/core's `Placement` exactly.

- **claim / move / restore** — batches of plot writes, one compare-and-set transaction each, answered
  `stale` when what the writer read no longer holds (two tabs placing alike converge).
- Bumping `LAYOUT_GENERATION` starts every world fresh (7: back to kin-leaning placement).
