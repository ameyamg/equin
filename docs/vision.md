# Vision

equin is a self-evolving app for the agentic era: one app that can replace all others, customized for each user, at the boundary of an application and an operating system.

It grows in three steps, and we are at the beginning of the third.

## 1. An agent manager that improves itself

The first app is an agent manager whose goal is to fix todos faster than they are created. It is used to improve itself.

- It is a nested todo list of the tasks agents run.
- Each agent works in its own isolated worktree and deploys to `http://<worktree>.localhost:<port>`.
- The UI switches between these namespaces, so the user can inspect each agent's work.

## 2. A Notion-like WeChat

The app grows into one unified surface where agents compose apps tailored to the user, on the fly, from plugin building blocks.

- Notion gives users composable blocks (databases, pages, views) to fit their workflow. equin does the same at the *app* level, with agents doing the composing.
- The agent manager becomes one such composition among many, sharing the same plugins and primitives.

## 3. A plugin marketplace

Users contribute and share building blocks in a marketplace.

- Agents assemble each user's own composition from marketplace plugins.
- The result is not a one-size-fits-all tool, but a personal OS shaped to its user's workflow.
- The author's own apps are just one set of plugins among many.
