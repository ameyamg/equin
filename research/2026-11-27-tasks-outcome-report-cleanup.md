# Outcome report cleanup: a hand-back is the last message, nothing more

## Context

Since `3ca862b4b1` (2026-11-26) a run's report *is* the agent's last message:
no tool writes it. But the machinery of the old filed report stayed under it:
a per-task table holding a copy of the message (`tasks_ext_outcome_report`),
its git-measured `standing` (a hand-back fails when git can't be measured), a
live collection, a transcript-end card repeating the message right above it,
and an automation History detail. The user asked to clean the system up: the
supervisor should hear the worker's last message, without a "report" record
in between.

## What stays (it answers a real question)

- `report.required` grant — the mandate fact "nobody watches this agent's
  transcript". **Not derived from "a watch exists"**: the supervisor preset
  grants `watch.children` to the root too, and interactive conversations can
  watch what they file; deriving it would put "the user is not watching" and
  the `turn_for` gate on agents the user is talking to. The grant is the
  author's declaration, kept.
- `runEnd` / `userInRun`, `turn_for` + its stop gate, the `asking` source, the
  question bell, the digest's `waiting on the user` / `asking the user`.
- The hand-back event feeding the `reported` watch source (the sanctioned
  way into `watch.ingest`; `watchSource` needs an event), and the live +
  backstop jobs.

## What goes

| Removed | Replaced by |
|---|---|
| `tasks_ext_outcome_report` (body, standing, messageId, submittedAt per task) | `outcome_report_handbacks`: per conversation, `message_id` + `handed_back_at` — only what `userInRun` and the dedupe need |
| `standing` + `getAttemptStanding` in the hand-back | nothing: `tasks.settled` / `tasks.stopped` already tell a watcher whether it landed; the worker's message says what's left |
| `outcomeReportRows` live collection + server `serveCollection` | nothing reads it any more |
| `OutcomeReportCard` (JsonlViewer.TranscriptEnd) | the message itself, already the transcript's last line |
| `OutcomeReportDetail` + `Automations.TaskDetail` slot (outcome-report its only contributor) and History's row `detail` | the History row already opens the task |
| digest `report: <first sentence>` | `handed back` (from the marker): still tells "done" from "mid-conversation"; the full message reached the watcher in its `reported` event |
| event payload `standing`, summary `report (<standing>):` | payload `{ taskId, conversationId, body }`, summary `last message:\n<body>` |

Event name `outcomeReport.submitted` → `outcomeReport.handedBack` (its trigger
table is regenerated by the build's migration step).
